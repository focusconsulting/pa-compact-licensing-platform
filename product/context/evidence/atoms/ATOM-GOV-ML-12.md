# ATOM-GOV-ML-12

The PA Compact Model Legislation (CSG model act, enacted by participating states) states, at §7.E.3.a, L662:

> "A Compact Privilege expires when the Licensee's Qualifying License in the Participating State from which the Licensee applied for the Compact Privilege expires."

This is a direct quote from the converted source file (`pa-compact-model-legislation.md`, L662); it is not a paraphrase.
