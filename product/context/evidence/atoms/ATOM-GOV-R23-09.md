# ATOM-GOV-R23-09

The PA Compact draft Rules 2 & 3 (redline approved by rules committee 2026-02-09) states, at Rule 3 §3.5(a), L580:

> "The expiration date of the qualifying license shall be the expiration date that was in effect on the date the PA applied for the compact privilege. Any renewal of the qualifying license does not automatically renew the compact privilege. The PA must follow the procedure set forth in this Rule in order to maintain any existing compact privilege(s)."

This is a direct quote from the converted source file (`pa-compact-rule-2-and-3-drafts.md`, L580); it is not a paraphrase.
