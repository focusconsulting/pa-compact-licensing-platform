# ATOM-GOV-R5-09

The PA Compact draft Rule 5 "Data System" (renumbered Rule 4 on 2025-11-10; earlier draft text) states, at §5.6(b), L1410:

> "When the Compact Commission receives notice of an adverse action, it shall promptly notify each Participating State where the PA holds a Qualifying License or a Compact Privilege of the adverse action."

This is a direct quote from the converted source file (`pa-draft-rules-2_3_5.md`, L1410); it is not a paraphrase.
