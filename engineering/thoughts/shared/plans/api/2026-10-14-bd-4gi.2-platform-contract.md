# Platform Contract (Epic 2 Contract Step) Implementation Plan

## Overview

Fix the signatures every feature builds against: how a change is recorded (`emit`, `history.write`, `audit.write`, `notify`, handler declarations), how a route declares who may call it (`require`, `public`), and the success and paging shapes. The row-writing functions ship as real, tested code; the logic owned by later tracks (`deactivate_privileges`, the dispatcher, sending email) is fixed as signatures in `engineering/docs/platform-contract.md` and becomes code in those tracks. Three PRs, each unblocking one track.

## Constitution Check

- **I.** Uses FastAPI dependencies, Pydantic models, and SQLAlchemy expressions; no new dependency. Shared errors stay `AppError`; one new code, `FORBIDDEN`.
- **II.** `require` runs server-side on every authenticated route. Record scoping (`404` for out-of-scope records) stays in each route's query; ADR-0009 says so.
- **III.** Every function is tested against real Postgres; `require` through HTTP routes. Coverage stays 100% on new code.
- **IV.** No stubs: everything merged is the production implementation. Unbuilt functions exist only as documented signatures.
- **VI.** `emit` refuses to run outside a transaction; `history.write` and `audit.write` run in the caller's transaction; audit columns resolve from the token `sub` by subquery in the same statement.
- **VII.** Compact and system admins pass state checks only when the route lists their role. Permissions are opt-in per state.
- **VIII.** Adds the request ID: on the response, the request log line, `domain_events`, and `audit_log`.
- **IX.** This plan links its ticket and flows; `EventType` is tested against FLOW-07's table.
- **XI.** Docstrings on every public name; `engineering/docs/platform-contract.md` holds the signatures and usage.

## Desired End State

A feature author writes a mutating route like this, and nothing else is needed for the record:

```python
@router.post('/states/{state_code}/qualifying-licenses/{license_id}/status', name=..., description=...)
async def change_status(
    state_code: str,
    license_id: UUID,
    body: StatusChange,
    caller: Annotated[User, require(Role.STATE_STAFF, Role.STATE_ADMIN, permission=Permission.WRITE, state_param='state_code')],
    ctx: Annotated[ChangeContext, Depends(change_context)],
    session: Annotated[AsyncSession, Depends(get_db_session)],
) -> Data[LicenseOut]:
    license = await get_license_in_state(session, license_id, state_code)  # 404 if out of scope
    before = snapshot(license)
    license.state_reported_status = body.status
    license.updated_by = actor_id(ctx.actor)
    await history.write(session, ctx, license, before=before)
    await audit_log.write(session, ctx, 'qualifying_license.status_changed', license, before=..., after=...)
    await emit(session, ctx, EventType.QUALIFYING_LICENSE_STATUS_CHANGED, license, {'qualifying_license_id': license.id})
    await session.commit()
    return Data(data=LicenseOut.model_validate(license))
```

Verified by: `just lint`, `just test-coverage` (100% on new modules), and each of `.3`–`.6` linking `platform-contract.md` from its plan.

### Key Discoveries

- SQLAlchemy accepts a SQL expression as an attribute value at flush ("embedding SQL insert/update expressions into a flush"), so `created_by=actor_id(actor)` resolves `sub → id` in the INSERT itself, as ADR-0004 requires.
- `chk_domain_events_one_aggregate_reference` and `chk_audit_log_one_entity_reference` already enforce one of `*_id`/`*_key`; the helpers pick from the model's primary key (`State` is keyed by `code`, `repo/state.py:28`).
- `notifications.idempotency_key` is `UNIQUE` (`20261007_090000_data_model_shared_roots.sql:387`), so `ON CONFLICT DO NOTHING` gives send-once.
- Test fixtures roll back via savepoints (`tests/conftest.py:76`, `:96`), so helpers can be tested with `db_session` and routes with `route_db_session`.

async def emit(session: AsyncSession, ctx: ChangeContext, event_type: EventType,

    Raises ``OutsideTransactionError`` when the session has no open transaction,

**File**: `engineering/api/licensing_api/events.py` (new)

```python
HandlerFn = Callable[[AsyncSession, ChangeContext, DomainEvent], Awaitable[None]]

@dataclass(frozen=True)
class Handler:
    name: str                       # '<owning module>.<what it does>', never the import path
    event_types: frozenset[EventType]
    run: HandlerFn

def handler(name: str, *event_types: EventType) -> Callable[[HandlerFn], Handler]:
    """Declare a handler (the ticket's ``register_handler``). Validates the name; registers nothing."""

class HandlerRegistry:
    """The handlers the Worker runs, built from a constant tuple so no module state changes at runtime."""
    def __init__(self, handlers: Iterable[Handler]) -> None: ...   # rejects duplicate names
    def for_event(self, event_type: EventType) -> tuple[Handler, ...]: ...
```

Name rule: `^[a-z][a-z0-9_]*\.[a-z][a-z0-9_]*$` (data dictionary, `domain_events`).

#### 5. History

**File**: `engineering/api/licensing_api/repo/history.py`

```python
def snapshot(entity: SQLModel) -> dict[str, Any]:
    """The entity's tracked fields as JSON values, taken before a change."""

async def write(session: AsyncSession, ctx: ChangeContext, entity: SQLModel, *,
                before: Mapping[str, Any] | None, effective_at: datetime | None = None) -> HistoryRecord | None:
    """Record one change to ``entity`` in its history table, in the caller's transaction.

    ``before`` is ``snapshot(entity)`` taken before the change, or None for a new row.
    Returns None and writes nothing when no tracked field changed.
    """
```

Tracked fields exclude `id`, `public_id`, and the four audit columns. Row contents:

- `previous`: the whole `before` snapshot (None for a new row), so each row stands alone.
- `updated`: fields whose value changed to a non-null value, with the new value.
- `removed`: fields that changed to null, with the value they had.

The entity → history-table map is a module constant over the nine history models; an entity without one raises `ValueError`. `changed_by=actor_id(ctx.actor)`.

#### 6. Audit

```python
class Role(StrEnum):            # chk_users_role
    LICENSEE = 'licensee'; STATE_STAFF = 'state_staff'; STATE_ADMIN = 'state_admin'
    COMPACT_ADMIN = 'compact_admin'; ADMIN = 'admin'

class Permission(StrEnum):      # D5; read_general is implicit for staff
    READ_PRIVATE = 'read_private'; READ_SSN = 'read_ssn'; WRITE = 'write'; ADMIN = 'admin'

@dataclass(frozen=True)
class RouteAccess:
    roles: frozenset[Role] | None   # None means public
    permission: Permission | None
    state_param: str | None

def require(*roles: Role, permission: Permission | None = None, state_param: str | None = None) -> Any:
    """``Depends`` that admits a caller whose role is in ``roles`` and, for state staff, who holds
    ``permission`` in the route's state (ADR-0009). Yields the caller's ``User``."""

def public() -> Any:
    """``Depends`` for a route with no caller check."""

def route_access(route: APIRoute) -> RouteAccess | None:
    """The declaration on a route, found in its dependency tree; None when it has none."""
```

Rules (ADR-0009): unknown user → `403 USER_NOT_FOUND`; inactive → `403 USER_INACTIVE`; role not listed → `403 FORBIDDEN`; `permission` checked only for `state_staff`/`state_admin`, against `users.permissions[state]`, where `state` is the `state_param` path value or the caller's `state_code`. Declaring `permission` without a staff role raises `ValueError` at import. The first-sign-in link by email moves here from `routes/user.py`.

## Security Impact Assessment

- **Data**: `audit_log` and history rows can hold private and States-and-Commission-tier values; `domain_events.payload` holds IDs only.
- **Flow**: written in the request's transaction; read only by later admin routes and the Worker.
- **Protection**: `emit` accepts only ID-typed payload values; `audit_log.write` documents that SSNs and expunged values are never passed; `practitioner_ssn` has no history table, so `history.write` cannot copy an SSN.
- **Authorization**: `require` closes the gap of a route shipping without a check (a test fails). Permission changes apply on the next request. Unknown and inactive users are refused before any route logic.
- **What could go wrong**: a route author passes a full record to `audit_log.write` including private fields that later surface in an admin view; the admin audit route (`GET /commission/audit`, `.3`) is `compact_admin`/`admin` only. An inbound `X-Request-ID` is length- and charset-limited, so it cannot inject into logs.
